# Defensive proofs of concept: Chebyshev recurrence and fixed XOR stream

These five files are newly authored from the case's mathematical method. They contain no challenge ciphertext, recovered key, or flag. The visible base value in the case record was illustrative. Run `python -B test_pocs.py` here. The tests use only invented data.

`chebyshev_lab.py` exposes slow and fast `T_n(x) mod p`, an independent 2x2 matrix evaluator, minimal big-endian keystream conversion, and cycling XOR. Inputs are integer `x`, nonnegative integer `n`, modulus `p >= 2`, and bytes. The fast paths cap `n` at 4,096 bits; the slow reference caps `n` at 100,000. This is a mathematical reproduction and 35-byte synthetic round trip. It is not an encryption library or a safe cipher. Keep the fast routine separate from any production key derivation.

`linear_recurrence.py` accepts constant coefficients, matching initial values, an index, and a modulus. It caps the order at 16 and the index at 4,096 bits. Companion-matrix exponentiation computes the requested term in logarithmic index steps. The tests compare it with the Chebyshev slow/fast paths and a known Fibonacci value. It is a general analysis aid, not a cryptographic primitive.

`recurrence_review.py` takes one Python source file of at most 256 KB and emits JSON findings with a line number. It parses source with `ast`; it never executes the file. It looks for a large integer literal and the expression shape `(2 * name * name - name) % name`. It does not prove that the code is malicious, cryptographic, or even a Chebyshev recurrence in context. Legitimate numerical code could match. The test suite supplies a positive, a benign large-prime use, and a near miss with a small modulus. Variable rearrangement, function calls, compiled code, and a separate constant module can evade this narrow rule. Review the surrounding code and the deployment context before acting.

Expected and observed local checks: four tests pass, including slow/fast/matrix/generic recurrence equivalence at nine small indices, an independent matrix check at `10**25`, a 35-byte synthetic cycle, detector positive/benign/near miss, and input bounds. No original binary, source repository, YARA engine, SIEM backend, or production telemetry was tested. The code-review sensor requires accessible Python source; there is no process-telemetry mapping because this detector does not consume process events.
