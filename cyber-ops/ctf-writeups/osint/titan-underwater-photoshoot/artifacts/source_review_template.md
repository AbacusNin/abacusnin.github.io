# Event-to-coordinate source review

Copy this form when a public event or record must be tied to a map point. Keep the source URL or a permitted capture with the completed copy. A name match alone does not establish that two sources refer to the same place.

| Field | Entry |
|---|---|
| Question and required precision | |
| Issuing record URL and access date | |
| Exact event category, holder, venue, and date | |
| Derivative coverage and shared origin | |
| Independent venue source and what it actually confirms | |
| Same-name or nearby candidate rejected, with reason | |
| Bounded query log and negative results | |
| Map pin URL, provider, read time, datum, latitude, longitude | |
| Pin vs. physical-site uncertainty | |
| Output format and local syntax check | |
| External acceptance or review evidence, if any | |

For a defensive exposure review, omit the published exact point when sharing it would create a safety or privacy problem. Preserve enough provenance internally to let a second analyst revisit the match. The coordinate checker in this folder verifies syntax and optional bounds; it does not establish the event or physical location.
